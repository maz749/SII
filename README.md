# Модуль 1. Базы знаний и онтологии

Оформление обновлено по присланному «Системы ИИ.pdf». В шаблоне: ЛР1, часть 1 -
Prolog; ЛР1, часть 2 - онтология; ЛР2 - DSS. Имена каталогов lab1/lab2/lab3
сохранены, чтобы прежние команды запуска продолжали работать.

Три лабораторные по пособию ИТМО «Системы искусственного интеллекта» (2024),
печатные стр. 56-58, структура расширенного отчета - стр. 73.

**Тема: подбор персонажа вымышленной фэнтезийной RPG.**
Десять персонажей-архетипов, роли, дистанция, доступность новичкам, оружие и противники.
Игровые характеристики заданы специально для учебной модели.

## Что сдавать

- `lab1/knowledge_base.pl` и `lab1/queries.pl` - факты, 7 правил и 10 запросов.

- `lab3/app.py` - программа с диалогом и вызовом настоящего SWI-Prolog.
- `output/pdf/lab1_report.pdf`, `lab2_report.pdf`, `lab3_report.pdf` - краткие отчеты.
- `output/pdf/module1_report.pdf` - расширенный отчет по приложению 2.
- `reports/*.md` - редактируемые тексты отчетов; указаны Бирюков Ян, группа 3321, проверила Королева Ю.А.
- `evidence/` - реальные журналы проверок, вывод запросов и примеры диалогов.

## Быстрый запуск

Нужны Python 3.10+ и SWI-Prolog (`swipl` в PATH). Для самой СППР пакеты Python не нужны.
Из корня проекта:

```bash
python3 lab3/app.py --fixed
```

Первая строка: `роль=урон; дистанция=дальняя`. Затем два уточнения:
`новичок` и `любой` → Следопыт. Поля `опыт` и `противник` можно включить
в первую строку; тогда перед результатом нужно ответить `да`.
Команда `выход` завершает диалог. Прежний режим четырех вопросов сохранен:
`python3 lab3/app.py`.

```bash
swipl -q -s lab1/queries.pl -g main -t halt
swipl -s lab1/knowledge_base.pl
```

В интерактивном Prolog: `protector(X).`, `armored_hunter(X).`; выход: `halt.`.

## Проверки и воспроизведение онтологии

Для OWL нужны Python-пакеты и Java (проверено с Java 17, Owlready2 0.48).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python tools/run_checks.py
python tools/capture_examples.py
```

В PowerShell активация: `.venv\Scripts\Activate.ps1`.
Версия Owlready2 закреплена для совместимости bundled Pellet с Java 17.

## Protégé

Откройте `lab2/rpg.owl`; пошаговая демонстрация и запросы - в `lab2/PROTEGE.md`.
Онтология создана программно и независимо проверена HermiT и Pellet. GUI Protégé в этой среде не проверен:
Homebrew блокирует установку из-за Gatekeeper. Перед демонстрацией в редакторе
выполните сценарий из инструкции; скриншоты редактора в комплект не входят.

## Отчеты

```bash
python tools/build_reports.py
```

Для сборки PDF нужны шрифты Arial/Courier New из macOS; в скрипте можно заменить
пути к четырем TTF на аналоги с поддержкой кириллицы.
Материалы воспроизводимы: факты в OWL экспортируются из `knowledge_base.pl`,
ответы для отчетов берутся из журналов фактических запусков.
Рекомендации являются точным отбором по условиям, без ранжирования и обучения.

Тексты Markdown являются редактируемыми копиями. Сборщик PDF берет содержание
из tools/build_reports.py; изменения только в Markdown не переносятся в PDF автоматически.

## Проверки и структура отчета

между Prolog/HermiT/Pellet и 3 отрицательных проверки OWL проходят.
В OWL добавлены beginnerFriendly (xsd:boolean), exactly 1 hasWeapon,
min 1 counters и AllDifferent для предметных индивидов.
Главный отчет - 15 страниц: титульный лист, аннотация, введение,
по 3 страницы Prolog/OWL/DSS, 2 страницы тестирования, оценка и заключение.
Краткие отчеты содержат по 3 страницы с отдельным титульным листом.
Правила оформления записаны в reports/FORMAT.md.
